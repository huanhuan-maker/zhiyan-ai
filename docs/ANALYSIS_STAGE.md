# M4-R｜固定问卷统计与可追溯分析

用户于本会话确认 UI 复核后授权开始本轮。本轮取代旧 M4 中依赖动态追问的安排，完成后停止等待验收。追问继续关闭；旧工程及记录保留。

交付：统一答卷与统计页面；按发布版本展示后端统计、有效/缺失分母；对核心开放回答生成带原文定位的候选主题；报告保存快照、人工通过/驳回及审计；导出 Markdown 和 JSON。数值只能来自后端，模型不能写题目或修改统计。主题计数仅为入选证据中可定位的不同答卷数，不外推为总体比例。核心开放回答不自动宣称为“自发提及”。

报告仅由所有者操作，真实模型发送需在产品中确认已有数据处理告知与授权。默认本地相同回答分组，不冒充语义模型；真实模式复用服务端 Provider。网络、超时、格式/引用校验失败保留既有报告，不影响答题。报告是生成时的数据快照，新答卷或改删使其标记数据变化，批准前必须重新生成。

本轮上限：单版本 5000 份答卷；模型证据最多 200 条/60000 字，单条超 2000 字不入选，覆盖与排除数量明确显示。所有统计仍覆盖该版本全量答卷；不使用前 200 条计算总体比例。暂不做因果推断、自动合并主题、公开发布报告、PDF/Word 排版或大样本异步任务。

验收：合成四题型真实发布/提交，独立复算统计；跨版本/跨用户/匿名拒绝；引用存在与原文一致、坏引用被拦截；新答卷标记陈旧、并发审核冲突、刷新与重启保留；真实模型标识与实际结果；手机 390px、ECharts、导出与失败恢复。报告见 `evidence/M4-R.md`。
