# M5-A｜问卷助手：只读 MCP 查询

用户明确要求将前一轮讨论的问卷助手加入工作台侧栏。入口位于“我的问卷”之后，普通用户可用，管理员另保留用户管理与系统配置。完成后停在本轮验收，不恢复追问。

本轮实现：独立对话页、问卷/版本范围选择、持久化对话、AI 问题理解与明确标注的本地降级、真实 MCP JSON-RPC 工具发现和调用，以及带查询时间/版本/分母/原文来源的结果。工具仅允许搜索自己的问卷、读取版本统计、关键词检索核心开放回答、读取已审核报告，不允许写业务数据或执行自由 SQL。

MCP 采用固定支持版本 2025-06-18 的本机 Streamable HTTP JSON 响应模式；协议来源为官方 lifecycle/transports/tools 文档。继续使用现有 Spring Boot / MyBatis-Plus / MySQL，不因引入 MCP 更换技术栈或强行升级 Boot。接口使用本应用认证，本轮不实现公网 OAuth 授权发现，不宣称通用远程客户端的完整认证兼容性。

站内页面充当 MCP 客户端，实际通过 HTTP 执行 initialize、initialized、tools/list、tools/call。模型仅将用户问题转换为受限工具请求，统计和原文回答由服务端工具生成，避免模型改写数字或引文；答卷原文不发送给规划模型。真实模式需确认发送提问文本。工具执行前再次校验所有权，管理员也不能通过此助手读取他人问卷。

本轮文本检索为实时、明确标注的字面关键词检索，不冒充向量语义搜索；无独立索引，新增/修改/归档即时影响新查询。单版本最多 5000 份答卷，返回证据最多 10 条，明确区分全量字面匹配数与返回证据数，不能推断观点总体比例。历史结果是查询时快照，不冒充最新结果；历史读取仍复核当前问卷权限。

暂不做自动写入/发布/删除问卷、跨版本可比性推断、跨人私有数据访问、向量数据库、自由 Text-to-SQL。验收覆盖真实 MCP 协议、权限/参数/提示注入边界、真实模型规划、AI 故障降级、浏览器实际 HTTP 调用、刷新/重启历史和 390px 页面。
