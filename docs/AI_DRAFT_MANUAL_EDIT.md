# AI 生成草稿的手动单题编辑

本轮是用户反馈“部分 AI 题目满意，部分需要手动改但没有入口”的缺陷修复，属于 M5-D 的体验补充，不进入新阶段。

## AI 建卷页

生成后，在“审核草稿”的每道题旁点击“编辑题目”。可以修改题干、题型、必填、选择题选项、评分范围和开放题回答提示。只替换当前题目，其他题目保持原样；编辑使用独立副本，取消或关闭弹窗不会修改原题。

保存前校验空白/过长/重复题干、空白/重复选项、2～20 个选项和 2～10 的整数评分上限。切换题型只适用于未发布 AI 草稿，并清理与新题型无关的选项/评分字段。单题修改不调用模型，不生成新问卷。原 AI 设计说明保留，页面提示手动调整后重新核对说明。

点击“保存修改”保存到本标签页草稿（sessionStorage），刷新可恢复；“导入编辑器继续编辑”才通过原 Spring Boot 接口经 MyBatis-Plus 写入 MySQL。预览使用修改后的题目，不提交答卷。导入后继续在现有编辑器保存，问卷仍未发布。浏览器存储被清理或标签页关闭后，未导入草稿不保证恢复。

## 问卷助手

聊天生成的含题目新建预览增加“保存草稿并编辑”。点击即确认创建未发布草稿，然后进入现有编辑器逐题手动修改。它沿用原确认接口、过期与所有权校验；与“取消”和普通“确认执行”入口共存。保存失败会显示错误，不跳转。

## 数据与范围

前端沿用 Vue 3、Element Plus 和现有问卷结构；后端仍为 Spring Boot、MyBatis-Plus、MySQL。本轮无后端、SQL 表结构或接口变更，无需新迁移。已发布问卷的冻结约束沿用现有后端。没有增加单题 AI 重写、整卷批量改写、自动发布等功能。
