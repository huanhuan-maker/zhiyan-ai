# M5-D｜问卷助手管理与对话出图

本轮来自用户授权：扩大助手的问卷相关能力，并解决“基于某个问卷出数据图”无法完成的问题。接续已有 M5-C 简单聊天界面；交付后停在本轮验收，不恢复动态追问，不开启下一阶段。

## 对话内的能力

一个输入框同时支持普通聊天、查找自己的问卷、读草稿或冻结版本题目、查看发布历史、统计分析、查开放回答原文、读已审核报告、获取分享链接、导出指定版本答卷。

统计回复内嵌 Apache ECharts：每日回收趋势、逐题有效/缺失堆叠图、逐题选项柱状图或单选环形图，以及样本概览、评分均值和说明。可以自然表达“基于‘某问卷’V1生成数据图”“把‘某题干’画成饼图”，也可在图内切换题目和图形。每张图可下载 PNG，分析结果可下载 JSON。

图表数值在 Spring Boot 后端经 MyBatis-Plus 读取 MySQL 计算；趋势与其他统计来自同一数据库快照。明确问卷版本、查询时点、有效分母、缺失和多选比例。无数据时显示提示，不制造演示数据。数据解读是统计规则生成的说明，未进行因果分析、显著性检验或总体推断。

## 管理操作与权限

管理操作共 12 种：新建空白草稿、改标题、改简介、替换全部草稿题目、追加题目、修改单题、删除单题、调整顺序、复制草稿、发布、停止收集、移入回收站。AI 设计问卷会返回校验后的新建预览。

每项管理操作先生成持久化的预览，用户在消息里点击“确认执行”或“取消”。确认前不改变问卷。预览 30 分钟有效，包含变更前内容与影响说明；问卷发生变化则拒绝旧预览。确认事务锁定消息及目标问卷，写入单条操作审计；并发点击、确认重试和取消后重试返回既有结果，不重复执行。

助手仅访问当前账号拥有、未归档、非文件夹的问卷，管理员也不能经助手越权访问他人问卷。发布时冻结快照；正在收集的问卷须先停收或复制后编辑。历史版本与答卷保留。归档为移入回收站，不永久删除。涉及已有跳转逻辑的删除题目/修改选项，要求转到编辑器核对；整体替换会明确提示清除草稿跳转逻辑。

MCP 提供 10 个工具：`search_surveys`、`survey_stats`、`search_answers`、`survey_report`、`survey_details`、`survey_versions`、`survey_share`、`survey_export`、`manage_survey`、`design_survey`。管理工具只生成预览，因此标记 `readOnlyHint=true`；模型没有确认工具。实际确认仅走登录用户 REST 接口 `POST /user/form/assistant/actions/{id}/decision`。后端严格白名单、所有权和状态校验不依赖模型的自律。

## 模型与数据传输

Provider 继续由已有系统配置统一管理。本轮真实验收使用“本机推理网关 / group/group”。普通聊天、复杂意图理解、问卷设计与部分题目编辑使用该配置模型；问候、清晰查询与部分管理指令走服务端规则。模型不可用时有明确降级提示。

规划模型只接收当前提问、选中编号、配置轮数内的同范围对话及有界工具摘要（结果类型、问卷标题/版本、答卷数、图表请求、操作类型）。答卷原文、完整导出内容和检索证据不发送给规划模型。原文和导出仍由当前用户浏览器经授权接口读取；自定义问卷题目本身可能包含识别信息，系统不会自动对回答内容做匿名化承诺。

## 边界

- 开放回答仍为字面关键词检索，没有增加向量数据库或语义 RAG。
- 当前分析与导出单版本最多 5000 份；超限明确拒绝，不用截断样本冒充全量。趋势跨度超过 3660 天时保留实际日期点，不无限补零。
- 对话题目编辑支持单选、多选、评分和文本；复杂组件、切换已有题型和跳转逻辑细节请用现有编辑器。
- 单次消息执行一项明确操作；复杂组合任务可能需要分步或澄清。自然语言识别仍可能不准确，所有管理操作须核对预览。
- 图形为当前版本的趋势、有效/缺失与选项分布；未实现任意统计作图、交叉分析、自动跨问卷/跨版本合并、原始答卷修改或自动审核结论。
- 不授予用户管理、系统配置、SQL、永久删除或修改冻结版本的权限。暂不支持逐字流式回复与中途取消。
