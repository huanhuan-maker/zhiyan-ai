# 知研 AI — 研究假设与评估协议草案 V1.0

## 1. 不应宣称的创新
“AI 能生成问卷”“AI 能对开放题追问”“能按回答汇总主题”都不构成未经对照证明的独占创新。Qualtrics 的 Conversational Feedback 已支持自适应追问、清晰度反馈与追问记录。本文只把**受约束主动探索 + 全问卷预算 + 来源可靠的跨人新维度发现**作为待检验的研究组合。

参考资料：
- Qualtrics 官方说明：https://www.qualtrics.com/support/survey-platform/survey-module/editing-questions/conversational-feedback/
- TypeSafe 官方 Jev 基本原语：https://docs.typesafe.ai/introduction

## 2. 研究问题（RQ）
- RQ1：单人追问在相同最大轮数/时长下，是否提高受调查目标相关、非重复的信息量？
- RQ2：全局预算控制是否比逐题独立追问更少浪费追问次数？
- RQ3：跨人新主题是否具有高精确率、良好去重能力且有原文证据？
- RQ4：引入 Jev 作为决策模型是否比规则/普通 LLM 具有统计显著且实际有意义的增益（效果/速度/成本）？
- RQ5：主动追问是否增加诱导、退出、后续固定问题回答变化？

## 3. 基线实验组
A. 结构化问卷，无追问。
B. 结构化问卷 + 普通 LLM 自由追问（和 D 相同次数上限）。
C. 结构化问卷 + 受约束 LLM，只澄清/深入，不探索新维度。
D. 结构化问卷 + 本方法，澄清/深入/有界探索 + 全局预算。
E. D 的 Jev 决策替换组（有实际 Jev API 后才开展；不是第一版前置要求）。

## 4. 数据与标注
- 先构建至少 3 个不同调查场景的合成测试用例：校园体验、消费满意度、公共服务反馈。明确合成数据不能证明真实人群效果。
- 再招募自愿参与的真实受访者，事先告知 AI 参与、匿名策略和退出权。随机分配到实验组；避免同一人填写多个互相影响的版本（必要时统计建模处理）。
- 独立标注员建立盲评参考：独立有效信息单元、主题是否真实且相关、是否为新维度、是否重复、追问是否诱导、来源是否准确。
- 两名以上标注员独立编码，记录分歧并仲裁，报告一致性（例如 Cohen's kappa 或适合该变量的指标）。正式样本量需要功效分析，不预先声称几十份问卷足以证明提升。

## 5. 可计算的评价指标
1. `new_valid_units_per_respondent`：每人新增的相关非重复语义单元数；必须定义清晰标注准则。
2. `new_valid_units_per_followup`：每次追问带来的新增有效单元。
3. `new_valid_units_per_minute`：每受访分钟新增有效单元，时间从真实交互事件记录；允许零追问组对比。
4. `unnecessary_probe_rate`：盲评认为不必要的追问 / 所有追问。
5. `leading_probe_rate`：带有诱导倾向的追问 / 所有追问。
6. `repetition_rate`：重复询问已明确内容的追问比例。
7. `completion_rate`、`skip_rate`、`survey_duration`：受访负担。
8. `novel_dimension_precision_recall`：发现维度与独立参考主题集的对应；只有合理建立召回参考标准后才计算召回率。
9. `theme_evidence_support_rate`：每条报告主题是否有可定位且支持其含义的原文证据。
10. `quant_claim_consistency`：报告中的每个数值能否与确定性统计输出一致。
11. `latency`、`model_calls`、`estimated_cost`：工程成本，假设与真实账单分开。

## 6. 严格防止评价自证循环
- 不能用同一个 AI 既生成追问、又担任唯一裁判来证明自己更好。
- 不以生成文字长度代表信息质量；统计可比性在核心题层面单独保证。
- 新主题“多次出现”≠“具有代表性”，追问后提及≠自发提及；报告必须标注分母、问法与暴露条件。
- 任何未校准的模型选择概率不能解释为受访者持有某观点的真实概率。
- 如果结果未显著优于基线，应如实报告，并保留合理基线替代方案。

## 7. 论文计划输出
研究假设、方法定义、架构及实现、数据标注方案、四组对照、消融实验（去掉新维度探索、去掉全局预算、替换 Jev）、结果统计、效度威胁、伦理与隐私讨论。
