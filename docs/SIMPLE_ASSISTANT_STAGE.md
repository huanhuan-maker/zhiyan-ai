# M5-C｜一个窗口完成聊天和问卷查询

用户先反馈“你好”无法发送，截图显示AI模式的确认项未勾选，发送被前端静默阻止；随后明确要求只保留简单对话，既能聊天也能查问卷。本轮按这个新交互替换M5-A的模式/版本/问卷前置面板，不进入向量RAG或写操作阶段。

页面只保留消息、输入和发送，以及新对话/历史。发送即按页面提示使用已配置模型，无前置勾选、模式或版本下拉。欢迎语本地立即回答；普通聊天调用真实Provider。问卷问题自动选择四个只读MCP工具；唯一匹配问卷继续查，多份匹配在回复里给选择按钮。可以自然表达V1或最新版本，当前问卷上下文以小提示显示，可清除。

数据查询保留服务端所有权、版本、后端统计、原文证据与来源。搜索唯一匹配后在同一消息内保存下一阶段计划，由浏览器继续真实MCP调用，最多三步，不让模型编造统计、引用、SQL或执行写操作。普通聊天历史包含最近配置轮数的用户提问和纯聊天回复，不包含问卷工具结果/原文；问卷数值始终来自后端。

聊天、查询计划与结果保存在原助手表，刷新/重启可恢复，无新增SQL。保留旧REAL/LOCAL接口供历史兼容与回归，其确认参数不再是站内发送的前置流程。真实配置仍由系统配置统一管理。详见`evidence/M5-C.md`。
