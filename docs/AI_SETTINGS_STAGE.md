# M5-B｜统一模型配置

用户复核指出系统配置中仍显示旧DeepSeek开关，要求参照三协议下拉框，支持自定义供应商、多模型、思考强度、上下文与输出限制。本轮修复这个配置断层，保持原技术栈与停用追问的范围，交付后等待验收。

入口：系统配置 → AI配置。管理员管理供应商及模型，普通用户只可使用所选默认模型，不可读取供应商地址或密钥。数据库经MyBatis-Plus持久化，默认模型统一用于问卷助手、AI建卷和报告；保存后立即生效。首次读取将已有私有服务端配置导入一次，之后以数据库为准；关闭真实AI不会被旧文件重新启用。

支持OpenAI Chat Completions、OpenAI Responses、Anthropic Messages；分别实现原生请求、鉴权及文本响应解析。每个供应商可配置名称、API根地址、Key、超时和最多30个模型；系统最多20个供应商。每个模型可自定义显示名、实际模型ID、思考强度、上下文窗口、最大输出Token及0–20轮历史提问。支持将不同参数组合保存为同一API模型的不同配置档。

上下文是应用侧预算，采用UTF-8字节加固定消息开销作保守估算，不声称精确分词或扩展模型真实能力。超限明确失败/降级，不截断已发布题目或来源证据。助手仅发送同一问卷/版本的最近成功提问，按所设轮数取最近项；不发送工具结果/答卷原文，0表示无历史。其余AI功能继续使用各自原来的单次输入与传输确认。

Key使用服务端本地32字节主密钥、AES-256-GCM随机nonce加密入库；管理员读取也不回显原值。空Key保留，变更地址或协议需要重新输入Key确认目标。主密钥在忽略目录，备份必须同时保留数据库与对应文件。配置并发采用revision校验，不覆盖他人修改。连接测试仅发送固定OK探针，需先保存；测试成功不代表所有业务提示词或全部模型参数都兼容。

协议字段与限制见`backend-extensions/ai-config/README.md`。迁移、实际测试、过程失败、截图和用户验收步骤见`evidence/M5-B.md`。
