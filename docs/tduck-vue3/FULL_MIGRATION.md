动态选项已支持嵌套数据路径、级联子项、加载失败重试及值/文字标签持久化；多选互斥已接入配置和答题行为。新增回归使用明确标注的合成远程选项源，问卷及答卷仍调用真实隔离后端，见 `evidence/tduck-full/ADVANCED_CHOICES.md`。运行时选项不会改写已发布 Schema。

本地题型答题回归包括：文本、数字、多行文本、日期、评分、排序、滑块、下拉、级联、单选、多选、图片选择、省市、子表单、三类矩阵；另检查四种展示题型和分页。27 种渲染加载通过不等于全部高级配置组合都已穷举。图片选择用静态选项验证，真实图片上传归后续存储联调。

设计器的完整 SFC 源码没有在这两个目录中找到：`tduck-front/node_modules/tduck-form-generator` 是 2.0.5 Vue 2 编译分发包。当前设计器/答题器为 Vue 3 原生组件，复用数据协议和题型配置，没有装载旧 Vue 2 运行时。手机预览中的 iframe 指向本工程的 Vue 3 预览页。头像裁剪目前为原生 canvas 适配，不能把它描述为原裁剪组件所有交互逐项一致。

## 后端修复及安全边界

补丁：`patches/tduck-backend/local-acceptance-fixes.patch`，保留上游 MIT LICENSE。修复导入答卷没有来源 IP 导致的 NPE；空 IP 显示未知；答卷更新校验实际问卷所有者；删除校验每条答卷所属问卷；私有新增要求所有权；公开提交在服务端检查填写密码；发布后停止也冻结核心题，通用更新不能改写状态解除冻结，批量添加逐项鉴权。

这些检查有真实 HTTP 回归，不能等同于对整个旧后端完成安全审计。原版公开结果页面对应接口在当前后端未实现，当前页面会明确显示未启用，不展示伪造答卷。尚未完成覆盖所有高级题型组合、外部 Provider、浏览器兼容性与大样本性能的验收；本阶段不执行公网生产发布。

## 数据库与恢复

没有新增业务表、修改列或破坏性 DDL。数据库迁移采用完整备份恢复到独立库；只读核对脚本见 `db/tduck/001_full_migration_audit.sql`。问卷 Schema、选项 label 伴随字段、矩阵与子表单结构保持与 TDuck 接口兼容。

管理员写操作测试只临时替换隔离库中的管理员登录资料，先备份，并在 `finally` 中恢复。真实账号/配置页不保存截图，凭证、运行 JAR、原库 SQL、日志和测试 Excel 均留在 Git 忽略的 `.local`。

原工程完整性核对：727 个源码/配置文件与备份一致，原部署 JAR 一致；原库业务表一致，仅 `ac_user` 与 `ac_user_token` 变化。用户已经确认期间使用过原系统；报告仍如实保留脚本非零退出，未回滚用户正常登录记录。

## 启动和验收

启动命令、环境与测试见 `tduck-vue3/README.md`。运行证据见 `evidence/tduck-full/M0.md`；当前修改完整路径清单见同目录 `FILES.txt`。旧的 API/风险/验收文件属于第一阶段历史记录，本文件描述现在的迁移版。
