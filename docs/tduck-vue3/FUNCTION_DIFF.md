# 原 Vue 2 与新 Vue 3 功能差异

| 功能 | 原 TDuck Vue 2 | 新 Vue 3 第一阶段 |
|---|---|---|
| 邮箱/手机号密码登录 | 已有 | 已接真实接口，处理初始改密/验证码要求 |
| 退出 | 清除本地登录 | 清除当前页签 sessionStorage；无服务端撤销接口 |
| 工作台/菜单 | 已有多业务入口 | 问卷工作台、版本与迁移，适配手机 |
| 我的问卷 | 已有 | 真实分页、名称搜索、状态筛选、文件夹导航、重试 |
| 问卷状态概览 | 已有其他面板 | ECharts 使用后端按状态 total；清楚标注目录范围 |
| 问卷元数据/题目详情 | 已有 | 所有权接口读取，纯文本显示富文本，显示必填及常见选项 |
| 完整表单预览/显隐逻辑 | 已有 | 未迁移；题目元数据不冒充填写预览 |
| 拖拽设计、发布、关闭、删除、回收站 | 已有 | 未迁移，不提供伪按钮 |
| 公开填写、保存、提交、微信/验证码 | 原系统提供 | 未迁移 |
| 答卷管理、导出、趋势、分母统计 | 原系统提供 | 未迁移；当前状态图不是答卷统计 |
| 用户/系统/存储/通知管理 | 原系统提供 | 未迁移 |
| AI 追问及可信主题证据 | 不能由 TDuck 基础业务自动获得 | 未开始 |

“原系统提供”依据本地源码入口，不表示本轮执行了原版每项功能测试。当前新前端没有 iframe、Vue 2 运行时或商业设计器组件。

旧 `D:\LcProject` 的问卷版本冻结、Token 生命周期、幂等提交、后端统计、研究方法规范、测试和证据值得保留。它与 TDuck 的账户、问卷和答卷模型不同，不能把两套后端直接混接。建议旧工程作为对照和测试资产存档，后续分阶段评估功能迁入 TDuck；本阶段不删除旧工程，也不把旧 M1 证据挪作新工程验收。
