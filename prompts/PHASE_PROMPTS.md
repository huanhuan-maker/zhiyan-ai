# 知研 AI｜逐阶段发给 Codex 的复制指令

> **每次只复制一个阶段。** M0 请使用根目录 `CODEX_KICKOFF.md`，本文件从 M1 开始。先完成前阶段人工验收，才发送下一段。全部阶段遵循 `AGENTS.md`、`docs/DEVELOPMENT_PLAN.md` 与老师规定的 Vue3+ECharts、SpringBoot+MyBatis-Plus。

## M1：基础问卷闭环

```text
我已自行验收 M0，通过后现在授权你仅执行 M1。
先读 AGENTS.md、docs/DEVELOPMENT_PLAN.md 中 M1、docs/ACCEPTANCE_GUIDE.md 中 M1、docs/ARCHITECTURE_AND_API.md。
请实际写出可运行的发起者登录/建卷/四题型草稿编辑/发布版本/匿名填答/幂等提交/基础统计，以及使用真实后端统计数据的 ECharts 图表。数据必须经 Spring Boot + MyBatis-Plus 持久化到 MySQL；不要用 JPA 或写死 UI 数据。
完成后执行后端测试、前端 build、M1 纵向集成测试，并创建 evidence/M1.md，包括命令、真实结果、启动及手动验收步骤。停止，不进入 M2。不能只回复方案。
```

## M2：AI 调研目标到可编辑问卷

```text
我已自行验收 M1，现在授权你仅执行 M2。
严格阅读相关计划与验收剧本。实现调查目标自然语言输入、必要澄清、后端 AI Provider、严格结构化输出校验、生成可编辑题目、人工确认后发布。真实 AI 与 Mock 状态必须明确显示；无 Key 时手工建卷仍可用。不得暴露密钥、不得让损坏 JSON 直接入库或发布。
请做正常生成、空目标、非法 Schema、Provider 超时/无 Key 的自动化和手工验证；创建 evidence/M2.md。停止，不进入 M3。
```

## M3：单人自适应追问（项目核心）

```text
我已自行验收 M2，现在授权你仅执行 M3：开放题的受约束主动探索。
按规格实现 SKIP/CLARIFY/DEEPEN/EXPLORE、状态机、相关性与偏差约束、每题和全卷预算、同意和跳过、结构化决策审计、AI 超时回退、不覆盖原始回答。EXPLORE 只能基于受访者自己提出的相关线索。不得将 Jev 概率直接作为信息增益，也不得以文字长度作为唯一判断。
必须跑至少六类可复现验收用例：模糊、具体、新维度、主动跳过、预算、AI 超时，并额外检查拒绝 AI 追问。填写 evidence/M3.md，逐项附实际结果。不要开发 M4。
```

## M4：跨受访者相关新主题发现（项目核心）

```text
我已自行验收 M3，现在授权你仅执行 M4。
从已完成且授权分析的回答及追问记录中抽取/归并新主题，必须带上真实来源证据、匿名会话和题目关联；区分 SPONTANEOUS、NEUTRAL_PROBE、SUGGESTED_OPTION、MODEL_INFERRED_UNCONFIRMED。支持主题接受、重命名、合并、驳回并持久化审核；不修改发布中的固定核心问卷。
用至少8份合成问卷做集成测试；查得出同伴影响类线索，且移除有关回答后主题应合理变化。虚构引用不能落库为已证实主题。输出 evidence/M4.md，停止。
```

## M5：ECharts 可信统计及报告

```text
我已自行验收 M4，现在授权你仅执行 M5。
完善 ECharts 图表：单选、多选、量表、回收趋势；所有数值来自后端计算、MyBatis-Plus/参数化 SQL 与真实 MySQL，明确分母、过滤条件与问卷版本。实现可核对的开放题主题报告、CSV 导出以及 AI 对确定性数据的有依据解释。统计和报告不得让 LLM 编造数字。
必须用已知10份答卷的数据集验证分子分母和图表，检查多选率、缺失值、刷新/resize/dispose、引用跳转与 CSV 中文。输出 evidence/M5.md，停止。
```

## M6：论文实验与质量交付

```text
我已自行验收 M5，现在授权你仅执行 M6。
实现可切换且可追踪的对照策略 A固定问卷、B普通LLM追问、C受约束澄清/深入、D本系统有界探索与全局预算。相同问卷与预算条件下导出匿名日志，提供合成测试集、指标统计程序、人工盲评模板、可复现命令及必要的安全/回归测试。
Jev 只在具备可核对的官方 API 和测试额度后作为可选 E 组，不得阻塞完成。请准备答辩演示脚本、Windows 从零启动文档、已知缺陷和证据，不宣称未经验证的算法提升。完成 evidence/M6.md 并停止。
```
