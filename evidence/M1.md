## Windows 复现命令

已有 `.env` 和 MySQL3306 已初始化，**无需覆盖配置或重新建库**。账户在 `.env` 的 APP_ADMIN_USER / APP_ADMIN_PASSWORD；bootstrap仅首次创建，不重置既有用户密码。

终端A：

```powershell
Set-Location D:\LcProject
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\Start-Backend.ps1 -JavaHome 'D:\jdk\jdk17'
```

终端B：

```powershell
Set-Location D:\LcProject\frontend
npm.cmd ci
npm.cmd run dev
```

自动验证（根目录，MySQL保持启动）：

```powershell
.\scripts\Start-Backend.ps1 -JavaHome 'D:\jdk\jdk17' -Test
Push-Location frontend
npm.cmd run build
Pop-Location
# 以下脚本自行启停Java，先Ctrl+C停止占用8080的后端
.\scripts\Verify-M1.ps1 -JavaHome 'D:\jdk\jdk17'
```

Verify-M1 每次创建新的明确标为合成验收的调查和两份答卷，不删除已有数据。最新调查/版本 ID 在 `evidence/m1-smoke.json`；分享链接在忽略的 `.local/m1-demo.json` 的 publicPath（只读 publicPath 即可，不输出其中 session token）。

访问 http://127.0.0.1:5173 ：`/login`登录/注册，`/`调查列表，`/surveys/new`建卷，`/surveys/{id}/edit`编辑发布，`/public/{token}`匿名填写，`/surveys/{id}/results`统计；`/statistics`仍是明确标记的M0环境诊断。API详见 `docs/M1_API.md`。
