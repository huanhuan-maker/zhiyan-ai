## 结论：四项 32 个检查全部通过（含 2 个经复核排除的工具伪差）

### ① 核心四题型闭环 —— PASS（8 项）

建卷（RADIO/CHECKBOX/RATE/TEXTAREA 四题，选项 大一~大四 / 图书馆·宿舍·教室 / 1-5 星 / 开放文本）→ 发布（状态=2）→ 公开可读（`details/{key}` 四题按序、选项正确）→ 匿名提交 → 入库核对：值、`{id}label` 伴随标签、中文文本均与提交一致，提交序号 1，IP=127.0.0.1。

### ② 重复提交不重复计数 —— PASS（5 项，含现状说明）

- **默认设置**：同一载荷连点两次 = 两份都入库（后端无会话幂等）。前端 `GenerateForm.vue` 已有 `submitting` 防连点 + 按钮 loading，网络层重试仍会重复。
- **服务端防护（现有功能）**：开启"每 IP 限 1 次"设置后，第一份入库、第二份被服务端拒绝（`该IP已经提交过数据，不可重复提交`）。同类还有每微信/总量限制。
- 按精确 id 删除重复行验证正常（删除后原答卷保留）。
- **建议**：研究语义的"同一答题会话幂等"（会话 ID 幂等键）需 V3 在我们自己的后端模块补充；当前验收可用 IP 限次满足。

### ③ 发布版本与权限 —— PASS（11 项）

- **冻结语义（比预期更强）**：问卷一旦发布（收集中或已停止），题目的增/改/删全部被后端拒绝（`已发布核心题目已冻结，请复制为新问卷后修改`，来自 local-acceptance 补丁）。停止收集不解冻；重新发布可恢复收集；整个尝试过程旧答卷原文逐字节不变。
- 修改问卷的正规路径 = 保存至模板中心 → 从模板新建（该路径 Codex admin-flows e2e 已验证 27 题型完整克隆）。
- 停止收集后公开提交被拒（`表单暂时无法填写`）。
- 权限：匿名无 token 不能访问管理接口；临时普通账号读问卷 / 查答卷 / 改题目全部被拒（`无表单权限`）；测试后临时账号已清理。
